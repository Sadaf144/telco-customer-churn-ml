# telco-customer-churn-ml
# 📊 Customer Churn Intelligence Platform

An end-to-end Machine Learning web application designed to predict customer churn risk for subscription-based businesses. Built using Scikit-Learn for machine learning and Streamlit for an interactive user interface.

## 🚀 Key Features
- **Individual Risk Assessment:** Interactive form input to analyze churn probability for a single customer.
- **Bulk CSV Batch Processing:** Upload complete customer datasets (CSV) to get instant churn probability scores and automated risk categorization for thousands of users.
- **Actionable Business Metrics:** Visual indicators showing high-risk churn percentages and overall retention analytics.
- **Report Download:** Export generated batch prediction reports directly in CSV format.

## 🛠️ Tech Stack
- **Language:** Python
- **Data Manipulation:** Pandas, NumPy
- **Machine Learning:** Scikit-Learn (Random Forest, StandardScaler, LabelEncoder)
- **Web Framework:** Streamlit
- **Deployment:** Streamlit Community Cloud

## 📈 Model Performance
- **Algorithm:** Random Forest Classifier
- **Accuracy:** ~79% on unseen test dataset
